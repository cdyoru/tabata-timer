# 运动计时器 (Tabata Timer)

一个极简的间歇训练计时器：**45 秒运动 + 15 秒休息**，自动循环。

## 下载

前往 [Releases](https://github.com/cdyoru/tabata-timer/releases/latest) 页面下载最新版 APK。

最新版直链：

```
https://github.com/cdyoru/tabata-timer/releases/latest/download/TabataTimer-v3.2.0.apk
```

## 功能

- 45 秒运动 / 15 秒休息自动循环，无需手动切换
- 中文语音播报：点击开始时播报「运动开始，3、2、1」，阶段切换时播报「休息」「运动开始」
- 每秒提示音：运动阶段高音、休息阶段低音，不看屏幕也能跟上节奏
- 倒计时最后 3 秒数字变橙色提醒
- 显示当前轮次
- 计时期间屏幕常亮
- 息屏或切到后台自动暂停

## 安装

1. 手机下载 APK 文件
2. 点击安装，系统提示「未知来源应用」时选择允许
3. 小米 / OPPO / vivo 等机型需先在「设置 → 应用 → 特殊权限 → 安装未知应用」中授权对应浏览器或文件管理器

## 系统要求

- Android 6.0（API 23）及以上
- 语音播报需要系统已安装中文 TTS 引擎（绝大多数手机自带）。
  若未安装，程序会自动降级为提示音，并在界面显示启用指引。
